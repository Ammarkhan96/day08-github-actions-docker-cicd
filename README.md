# Day 08 - GitHub Actions Docker CI/CD

A practical CI pipeline using GitHub Actions, Python,
pytest and Docker.

## Features

- Automated CI pipeline
- GitHub Actions workflow
- Python application
- Automated unit testing
- Docker image build
- Docker container execution
- HTTP health check
- Pipeline failure on unsuccessful tests
- Automatic container cleanup
